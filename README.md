# 厦门博饼 · 线上线下一起玩

一个独立、零依赖的博饼网页。虚拟玩家由浏览器随机掷骰，现场朋友使用真实骰子并手动录入，适合远程伙伴和一桌真人一起玩。

## 使用

在目录里启动任意静态文件服务器，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。网页无需服务器账号、API Key 或 AI 模型。场次只保存在当前浏览器的 `localStorage`，不会上传。

## 玩法

1. 添加玩家，选择“虚拟”或“现场”。
2. 定顺序：虚拟玩家自动掷一颗；现场玩家自行掷一颗并录入点数。同点者单独重掷。也可以跳过定点，按名单顺序直接开始。
3. 按当前轮次投六颗骰子。虚拟玩家点击按钮；现场玩家把现实骰子录入。
4. 页面显示每次奖项、累计与暂定状元。后出的更大状元可以抢掉前一个，完全同级同带点则先博到者保留。
5. 点击“结束并公布结果”查看最终累计与状元。

本项目采用常见的厦门状元级别：四红 < 五子 < 五红 < 插金花 < 六勃黑 < 六勃红。地方和家庭对特殊奖项可能有不同约定，请在开桌前统一规则。此版本不处理奖品库存或“三红/对堂追饼”。

## 集成

`engine.js` 是不依赖界面的规则与场次模块；`index.html`、`app.js`、`style.css` 是示例网页。可将规则模块用于自己的聊天程序，但请让聊天系统负责人物回复、消息同步和持久化。此开源版不包含聊天记录、人物设定或私人资料。

运行规则测试：

```bash
npm test
```
